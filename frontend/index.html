FAQ

Common questions about the toolkit.

What hash types can devastator identify?

+

22 hash types: MD5, SHA-1, SHA-224/256/384/512, SHA3, bcrypt, NTLM, MySQL 3/4.1, RIPEMD-160, GOST, Whirlpool, CRC32/64, BLAKE2, and more. Detection uses length and charset heuristics at 85-95% accuracy.

How does dictionary cracking work?

+

The engine hashes each wordlist entry with all supported algorithms and compares against the target. Custom wordlist paths are supported; defaults to wordlists/rockyou.txt.

What are the brute-force limits?

+

Max length: 6 characters. Capped at 20M computations per request. Charsets: lowercase, lowercase+digit, full alphanumeric. Rayon-parallel for performance.

Which ciphers support auto-detection?

+

All seven ciphers support manual selection. Auto-detection scans Caesar, ROT13, Atbash, Base64, Hex, Binary, and Vigenere via charset scoring and readability heuristics.
