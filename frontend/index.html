About

devastator identifies hash types, cracks short hashes via dictionary or brute-force, and encodes/decodes classical ciphers. Built for CTF and education.


API endpoints (also available via HTTP):

POST /api/hash/identify — detect hash type POST /api/hash/crack — dictionary crack POST /api/hash/bruteforce — brute-force attack (max 6 chars) POST /api/cipher/detect — auto-detect cipher POST /api/cipher/decode — decode ciphertext POST /api/cipher/encode — encode plaintext
curl -X POST http://localhost:8080/api/hash/identify \ -H 'Content-Type: application/json' \ -d '{"hash":"5f4dcc3b5aa765d61d8327deb882cf99"}'

Hash types

  • MD5, SHA-1, SHA-224/256/384/512
  • SHA3-224/256/384/512
  • bcrypt, NTLM, MySQL 3/4.1
  • RIPEMD-160, GOST, Whirlpool
  • CRC32/64, Adler32, BLAKE2

Ciphers

  • Caesar (brute-force all 25 shifts)
  • ROT13, Atbash
  • Base64, Hex, Binary
  • Vigenère (key-based)
