Supported algorithms

22 hash types and 7 cipher methods with auto-detection.

H01

MD5

128-bit hash, 32 hex chars. Common in legacy systems.

H02

SHA-1

160-bit hash, 40 hex chars. Used in Git and TLS.

H03

SHA-256

256-bit hash, 64 hex chars. Industry standard.

H04

bcrypt

Adaptive hash with cost factor. Password storage.

H05

NTLM

Windows authentication hash. MD4-based.

C01

Caesar

Shift cipher. Brute-force all 25 shifts.

C02

Base64

Binary-to-text encoding. 4-char blocks.

C03

Vigenere

Polyalphabetic cipher with key-based shifts.

Capabilities

Engine limits, supported operations, and detection heuristics.

Engine

Hash identification

22 hash types detected via length and charset heuristics. Supports MD5, SHA-1/224/256/384/512, SHA3, bcrypt, NTLM, MySQL, RIPEMD-160, GOST, Whirlpool, CRC, BLAKE2, and more.

Accuracy: 85-95% on known types
Engine

Dictionary cracking

Multi-algorithm dictionary cracker. Supports MD5, SHA-1/224/256/384/512, NTLM, MySQL 3 and 4.1+. Iterates through all possible type identifications automatically.

Wordlist: rockyou.txt compatible
Engine

Brute-force

Rayon-parallel brute-force engine with configurable charset and max length. Capped at 20 million hash computations per request for server safety.

Max length: 6 characters | Charsets: lower, lower+digit, alphanumeric
Engine

Cipher operations

Seven classical cipher codecs with encode, decode, and auto-detection. Caesar (all 25 shifts), ROT13, Atbash, Base64, Hex, Binary, and Vigenere.

Detection via charset scoring and readability heuristics
