About

devastator is a hash identification and cracking toolkit with classical cipher support, built for CTF and educational use.


API endpoints (also available via HTTP):


POST /api/hash/identify — Detect hash type

POST /api/hash/crack — Dictionary crack

POST /api/hash/bruteforce — Brute-force attack

POST /api/cipher/detect — Auto-detect cipher

POST /api/cipher/decode — Decode ciphertext

POST /api/cipher/encode — Encode plaintext


Example: curl -X POST http://localhost:8080/api/hash/identify -H 'Content-Type: application/json' -d '{"hash":"5f4dcc3b5aa765d61d8327deb882cf99"}'

Hash Types

  • MD5, SHA-1, SHA-224/256/384/512
  • SHA3-224/256/384/512
  • bcrypt, NTLM, MySQL3/4.1
  • RIPEMD-160, GOST, Whirlpool
  • CRC32/64, Adler32, BLAKE2

Ciphers

  • Caesar (brute-force all shifts)
  • ROT13, Atbash
  • Base64, Hex, Binary
  • Vigenère (key-based)
